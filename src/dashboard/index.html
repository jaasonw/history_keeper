    How this works

    Pick a folder inside Google Drive, OneDrive, or Dropbox. Each device appends to its own monthly .ndjson shard inside a history-keeper subfolder and reads the others. Nothing is ever written by two devices, so the cloud client has no conflicts to resolve.
