Page text

Off by default. When on, the text of each page you visit is stored alongside the visit, so you can find a page by something you read on it rather than only by its title or address. Text is compressed, kept on this device, and never sent anywhere — the extension makes no network requests either way.

Turning this on asks Chrome for permission to read the pages you visit, which is what makes reading their text possible. Blocklisted sites are skipped, and you can revoke the permission at any time from chrome://extensions.

…

Text rides its own files in the sync folder, separate from the visit shards and skipped entirely by older versions of this extension. Compressed it is roughly 2.7 KB per page — about 54 MB for 20,000 pages — against a few hundred KB for the visits alone, so leave it off if the folder is somewhere tight.

The device id tags every visit this machine captures and names its shard files in the sync folder. The label is only for your own reference.

The dashboard and popup remind you to download a snapshot on this cadence. Quarterly by default; the reminder is only a nudge — nothing is deleted if you ignore it, and downloading a snapshot clears it until the next one is due.

…

Both also repair titles. A page is archived the instant you navigate to it, which is before the browser knows its title — on sites that swap pages without reloading, like YouTube, well before. Re-reading the visit later fills the title in. The re-scan reaches everything Chrome still remembers; the sweep only the last 20 minutes.
